# WHO CAN SAY NO?

*A Field Manual for Sovereignty, Compromise, and Institutional Power*

This repository contains a GitHub Pages-ready single-page HTML e-book.

## Files

- `index.html` — the full manuscript converted into a single HTML page.
- `styles.css` — typography, layout, navigation, and responsive styling.
- `script.js` — small navigation helper for mobile menu and active section highlighting.

## View locally

Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Upload these files to the root of the repository.
2. Go to repository **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/root` folder.
5. Save. GitHub will publish the site after the Pages build completes.
