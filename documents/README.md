# Documents

This folder is reserved for manuscript source material and editorial working files for **WHO CAN SAY NO?**

Use this folder for:

- full manuscript drafts
- chapter files
- case studies
- glossary source text
- editorial notes
- exported plain text or Markdown
- source material that will later be converted into the HTML edition

Suggested naming convention:

```text
00-introduction-compromise.md
01-core-architecture.md
02-diagnostic-method.md
03-structural-logic.md
04-ordinary-life.md
05-institutional-layer.md
06-case-study-method.md
07-case-study-covid.md
08-case-study-gaza.md
09-case-study-911.md
10-final-moral-correction.md
11-final-addendum.md
manuscript-full.md
```

Keep source files here separate from the public web files at the repository root, such as `index.html`, `styles.css`, and `script.js`.
