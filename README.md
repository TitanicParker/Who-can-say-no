# WHO CAN SAY NO?

*A Field Manual for Sovereignty, Compromise, and Institutional Power*

This repository contains the working materials for **WHO CAN SAY NO?**, a long-form political and philosophical manuscript about sovereignty, compromise, dependency, debt, institutional power, media, technology, war, crisis, and the human layer.

The project is intended to become a restrained, readable, GitHub Pages-ready HTML e-book. The design direction is austere rather than sensational: warm manuscript background, serious typography, clear navigation, and a literary-systems presentation rather than a blog, academic PDF, or partisan landing page.

## Repository structure

```text
/
├── README.md
└── documents/
    └── README.md
```

## Documents folder

The `documents/` folder is reserved for manuscript source files, chapter drafts, exported text, editorial notes, and other working materials.

Suggested future structure:

```text
documents/
├── manuscript-full.md
├── introduction-compromise.md
├── part-01-core-architecture.md
├── part-02-diagnostic-method.md
├── case-study-covid.md
├── case-study-gaza.md
├── case-study-911.md
└── final-addendum.md
```

## Future web build

When the HTML edition is added, the repository can use a structure like:

```text
/
├── index.html
├── styles.css
├── script.js
├── README.md
└── documents/
```

GitHub Pages can then be enabled from the repository settings by publishing from the `main` branch and the repository root.

## Editorial note

This project is a literary and systemic model. It is not a live news source, legal source, financial source, medical source, or academic reference database. Its purpose is to present a framework for reading dependency, compromise, institutional power, crisis, and sovereignty.
